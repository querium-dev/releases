# Querium

A cross-platform database IDE. PostgreSQL-first, careful with production.

**[Download at querium.dev →](https://querium.dev)**

## What this repository is

Releases. Every version's installers are attached to its tag, and
`stable/latest.json` is the manifest installed copies check for updates.

## Issues

Bug reports and feature requests are welcome in
[Issues](https://github.com/querium-dev/releases/issues). Useful things to
include: your operating system, the Querium version from **Help → About**, and
the database engine and version you were connected to.

Please do not paste connection strings, passwords, or real data.
